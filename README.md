# DM Skill Analyzer

ドラムマニア（GITADORA DrumMania）のスキルポイントを分析するブラウザツールです。
ビルド不要・サーバー不要で、`index.html` をブラウザで開くだけで動きます。

## 機能

- **総スキル計算**: HOT / OTHER それぞれ上位25曲の合計。同じ曲は最もスキル値の高い譜面だけが対象
- **スキル色表示**: 現在の色と、次の色までの残りスキル
- **概要**: 各枠の対象曲一覧、ボーダー、平均、難易度帯ごとの分布、ランク分布、傾向コメント
- **スコア管理**: 追加・表上で直接編集・HOT/OTHER 切替・削除・並べ替え・絞り込み
- **伸びしろ分析**: 各譜面を「次のランク」または「+N%」まで伸ばしたときの総スキル増分（枠の入れ替えも考慮）
- **ボーダー表**: 新しい譜面を枠に入れるのに必要な達成率（レベル別）
- **計算機**: スキル値計算 / 必要達成率 / 目標総スキルまでの必要量とおすすめ譜面
- **データ**: CSV/TSV のインポート・エクスポート、サンプルデータ。保存先はブラウザの localStorage

## 計算式

- 譜面スキル = レベル × 達成率(%) × 0.2（小数第2位未満は切り捨て）
- 総スキル = HOT 上位25曲 + OTHER 上位25曲
- ランク: SS ≥ 95%, S ≥ 80%, A ≥ 73%, B ≥ 63%, C それ未満

スキル色の区分はバージョンで変わることがあるため、`js/skill.js` の `COLORS` で調整できます。

## CSV 形式

```
song,diff,level,rate,category
曲A,EXT,8.20,91.30,HOT
曲B,MAS,9.05,78.12,OTHER
```

日本語ヘッダー（`曲名,難易度,レベル,達成率,種別`）や、ヘッダーなし（同じ列順）、タブ区切りも読み込めます。
